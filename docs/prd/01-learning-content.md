## Authoring requirements

| Content element | Requirement | Type |
| --- | --- | --- |
| Core explanation | Provide anatomy and physiology explanations that connect structures to functions. | EXPLICIT |
| 3D organ information | For selectable major organs: name, location, and basic function. Major organs expressly named: brain, lungs, heart, liver, stomach, kidneys, intestine, bones, muscles. | EXPLICIT — Scene 5 |
| Process content | Supply correct labels and sequences for air path, blood circulation, food journey, neural impulse, and urine formation where used in activities. | EXPLICIT |
| Practice items | Author anatomy-vs-physiology classification, structure–function matching, anatomical placement, organ/system classification, labelling, pathway sequencing, and puzzle items. | EXPLICIT |
| Question items | Author multiple-choice, true/false, and case-study evaluation content. | EXPLICIT |
| Feedback content | Provide scientific/concept explanations for automatic immediate feedback, not only correct/incorrect state. | EXPLICIT |
| Case content | Preserve educational/simple framing; avoid presenting it as diagnosis or treatment guidance. | EXPLICIT / INFERRED |
| Summary and glossary | Provide end-of-learning material summary, glossary terms/definitions, and reflection prompts. | EXPLICIT |
| Intro media | Provide introductory video and interactive infographic for pre-learning. | EXPLICIT |

## Content quality gates — PROPOSED

1. A qualified anatomy/physiology subject-matter expert reviews every organ label, sequence, answer key, feedback explanation, and case framing.
2. Record source/citation, reviewer, version, and approval date for each content item.
3. Review reproductive-system material for age-appropriate language and curriculum alignment.
